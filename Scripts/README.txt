## ------- Pollen_CHAR.Rmd ------- ##

This analysis is computed only for Baiau Superior. It includes:
 -(micro)Charcoal accumulation rate (CHAR);

 - Sediment accumulation rate (SAR);

## ------- Taxa_harmonisation.Rmd ------- ##

Includes the harmonisation across the morphotypes identified to get an unified taxa list for both lakes.

## ------- Diversity_estimates_50yr.Rmd ------- ##

The analyses are carried out including and excluding the simples within the paraconformity.

Includes:

 - Equalisation of temporal resolution within 50yr fixed temporal bins;
 - Sample coverage standardisation;
 - Diversity estimates (richness, exp. Shannon, evennes) calculation;
 - Linear and segmented model fitting and comparison;
 - Generalised Additive Model fitting.
 - Combined plots (Figs within columns a, c; Figs within columns b and c) to build up Fig. 5.
